# Flashcards для Android

Клиент к Flashcards API на Kotlin и Jetpack Compose. Работает с методами, которые уже есть на сервере:
регистрация, вход, профиль (`/auth/me`), список колод, просмотр, создание, изменение и удаление колоды.
Карточки и повторение добавятся, когда на сервере появятся их ручки.

## Как запустить

1. Поднять API локально (из корня репозитория), он слушает `localhost:8080`.
2. Открыть папку `android/` в Android Studio, дождаться синхронизации Gradle.
3. Создать эмулятор в Device Manager (например, Pixel 8, API 35) и нажать Run.

Из эмулятора компьютер виден как `10.0.2.2`, поэтому по умолчанию клиент ходит на
`http://10.0.2.2:8080/api/v1/`. Для телефона в той же Wi-Fi-сети адрес задаётся при сборке:

```
./gradlew installDebug -Pflashcards.apiBaseUrl=http://192.168.1.10:8080/api/v1/
```

Открытый http разрешён только для `10.0.2.2` и `localhost` (`res/xml/network_security_config.xml`),
для другого адреса его нужно добавить туда же.

## Устройство

- `core/` — чистый Kotlin без Android: модели из `api/openapi.yaml`, Retrofit-интерфейс, токены и репозитории.
  Тесты на MockWebServer: `./gradlew :core:test`.
- `app/` — Android-приложение: экраны на Compose, ViewModel, навигация, хранение токенов.

Авторизация: `AuthInterceptor` подставляет access-токен, `TokenAuthenticator` на 401 вызывает
`POST /auth/refresh` и повторяет запрос. Если обновить токен не вышло, сессия очищается и открывается экран входа.
Пока на сервере нет `/auth/refresh`, после истечения access-токена (15 минут) придётся войти заново.
